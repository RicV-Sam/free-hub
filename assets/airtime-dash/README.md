# Airtime Dash sharing artwork

`share-v1.png` is a 1200 × 630 FreeHub brand composition for Open Graph and Twitter link previews. `share-v1.svg` is its editable vector source. It uses the existing approved `assets/mascot/welcome-v1-640.webp` without altering the character, FreeHub's FH wordmark treatment and the original level-one maze from `functions/airtime-dash/engine.js`.

The mascot's generation prompts and provenance remain in `scripts/lib/mascot-provenance.json`. This is game and brand artwork, not official artwork for an external competition or an eligible competition entry. No new AI image was generated. The composition was rendered from SVG using the bundled Sharp image renderer on 6 October 2026, then visually inspected.

The image intentionally has no prize amount, opening status or closing date. It stays accurate after a competition closes. The game uses the same canonical page for ordinary and friend challenge links; individual score targets are resolved by the server on the landing page, not embedded in this shared image. Real WhatsApp previews can cache older images and still need a human check on a phone after publication.
