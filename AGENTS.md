# FreeHub editorial artwork standard

For every new competition, reward or offer listing:

1. Inspect the actual official campaign/provider page for suitable hero artwork first. Prefer relevant official artwork over a newly generated replacement. A generic site logo is not a completed hero image.
2. If suitable official hero artwork is unavailable or cannot be obtained, create a subject-specific image with the image-generation tool. Do not invent prizes, product models, amounts, mechanics or promoter endorsements. For design competitions, do not present generated artwork as an eligible entry.
3. Identify generated artwork visibly as a FreeHub editorial illustration. Record official source URLs or generation prompts and image provenance. Preserve existing factual content and entry requirements.
4. Save optimized assets inside the repository, provide descriptive alt text, and inspect the rendered desktop and mobile result before release. Verify the deployed image loads.
5. Use the existing competition image fields; use `data/listing-images.json` for reviewed image metadata and reward/offer hero rendering. Keep metadata consistent with the saved asset.

This standard was explicitly requested by the user on 17 September 2026. Apply it to future listing publication, not only this batch.
